# Final Demo Script

## Demo Duration
**Recommended duration:** 5–7 minutes

---

## 1. Opening

Good morning everyone.

Our project is **RSU Campus Buddy (Smart Campus Chatbot with AI Image Recognition)**.

The purpose of this system is to help students, visitors, and university staff easily identify campus buildings by simply uploading a photo. Instead of searching through maps or asking for directions, users can receive building information instantly using AI image recognition.

Our prototype uses **Google Teachable Machine**, **Python Flask**, and a **building information database** to provide an intelligent campus navigation experience.

---

## 2. User Scenario

Imagine a new student arrives at Rangsit University for the first time.

The student sees a building but doesn't know its name or what services are available inside.

Instead of searching online or asking someone for directions, the student opens **RSU Campus Buddy**, uploads a photo of the building, and immediately receives:

- Building name
- Description
- Facilities
- Student clubs
- Opening hours
- Floor information
- Campus directions

This helps students save time and navigate the campus more efficiently.

---

## 3. Prototype Walkthrough

| Step | Screen/Feature | What to Demonstrate | Requirement ID |
|---|---|---|---|
| **1** | Landing Page | Introduce the project, target users, problem statement, key features, and "Try the Chatbot" button. | FR-01 |
| **2** | AI Image Upload | Upload a campus building image and demonstrate Google Teachable Machine recognizing the building. | FR-03 |
| **3** | Building Directory | Show the complete list of campus buildings and available facilities. | FR-05 |
| **4** | Search Function | Search for a building using the search bar and display matching results. | FR-06 |
| **5** | Building Detail Page | Open a building information page showing facilities, opening hours, clubs, floor plans, and directions. | FR-07 |
| **6** | AI Recognition Result / Admin Panel | Show the AI prediction result and demonstrate how administrators can update building information. | FR-08, FR-09 |
| **7** | Dashboard & Metrics | Display acquisition metrics including chatbot visits, image uploads, buildings mapped, and user feedback. | FR-11 |

---

## 4. Evidence and Validation

Before the final release, five users tested the prototype.

The testing showed that:

- Users understood the purpose of the system immediately.
- Most users successfully uploaded building images without assistance.
- Users found the building directory and search function easy to use.
- The AI image recognition feature was considered useful and innovative.
- Feedback suggested improving recognition accuracy by training the AI model with additional building images from different angles.

Based on this feedback, we improved the user interface, documentation, landing page, and prototype workflow before the final release.

---

## 5. Closing

In conclusion, **RSU Campus Buddy** provides a faster and smarter way to explore the university campus using AI image recognition.

Our prototype combines modern AI technology with an easy-to-use web interface to help students identify buildings and access important campus information instantly.

For future development, we plan to:

- Train more campus building images to improve AI accuracy.
- Add indoor navigation.
- Expand the campus database.
- Develop a mobile version.
- Integrate Google Maps and official university information.
