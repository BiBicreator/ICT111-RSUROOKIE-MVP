# Acquisition Metrics

## Purpose

Measure early user interest, engagement, and prototype performance for the **RSU Campus Buddy** landing page. These metrics help the team evaluate whether users understand the project's value and are willing to explore the AI-powered campus navigation prototype.

## Required Metrics

| Metric ID | Metric Name | What It Measures | Formula / Counting Method | Data Source | Target / Success Criterion |
| --- | --- | --- | --- | --- | --- |
| M-01 | Landing Page Views | Number of visitors who opened the Campus Buddy landing page | Count page views using JavaScript (`localStorage`) or simulated tracking | Landing page | At least **20** page views |
| M-02 | Chatbot CTA Clicks | Number of users who clicked the **Try the Chatbot** button | (CTA Clicks ÷ Landing Page Views) × 100 | Landing page JavaScript | At least **30%** click-through rate |
| M-03 | Chatbot Visits | Number of users who opened the Campus Buddy chatbot prototype | Count visits to the chatbot page (`frontend.html`) | Prototype (simulated tracking) | At least **10** chatbot visits |
| M-04 | Feedback Responses | Number of users who submitted prototype feedback | Count completed feedback forms | Google Form / Manual record | At least **10** responses |
| M-05 | Interest Conversion | Percentage of visitors who interacted with the prototype after visiting the landing page | (Chatbot Visits ÷ Landing Page Views) × 100 | JavaScript metrics / Spreadsheet | At least **20%** conversion rate |

## Interpretation

If the acquisition metrics are below the target values, the team will improve the landing page and prototype by:

- Making the headline clearer and more engaging.
- Improving the visibility and wording of the **Try the Chatbot** button.
- Simplifying the user journey from the landing page to the chatbot.
- Adding clearer explanations of the AI image recognition and campus navigation features.
- Promoting the prototype to more RSU students to increase testing participation.
- Collecting additional user feedback and refining the interface based on suggestions.
