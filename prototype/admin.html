📋 How to Integrate Your Teachable Machine Model

Your index.html has a clearly marked /* ── TEACHABLE MACHINE PLACEHOLDER ── */ section. Paste your model code there.

/* ── TEACHABLE MACHINE PLACEHOLDER ── */ // 1. Go to teachablemachine.withgoogle.com → Train your image model // 2. Export → "Tensorflow.js" → Copy the model URL // 3. Paste the URL in the Admin Panel → AI tab → Model URL field // 4. The frontend will automatically load and run your model // The integration point in index.html looks like this: const MODEL_URL = localStorage.getItem('tm_model_url') || ''; // Your trained classes should match building names, e.g.: // Class 0: "Library" → maps to building LIB // Class 1: "Engineering" → maps to building B6 // Class 2: "Cafeteria" → maps to building CAF // (configure mappings above in the Label Mapping section)
