The Problem

New students at RSU often struggle to find buildings, offices, and services on the large campus. Important information is scattered across notice boards, Facebook groups, and word-of-mouth — leading to confusion, missed appointments, and wasted time.

  • 🗺️ No interactive campus map
  • 📋 Hard to find club meeting locations
  • 🕐 Inconsistent opening hours info
  • 🔄 Staff receive repetitive inquiries

The Solution

RSU Smart Campus Navigator is an AI-powered chatbot that identifies campus buildings from photos and instantly delivers structured information — reducing confusion and freeing up staff time.

  • 📸 Upload any building photo → instant ID
  • 🧭 Step-by-step indoor navigation
  • 🏗️ Floor-by-floor room maps
  • 💬 Chat history saved locally

What it does

Key Features

Three integrated tabs working together to guide every RSU student.

💬

AI Image Chat

Upload a photo of any RSU building — inside or outside — and the AI identifies it using Google Cloud Vision, returning full building info instantly.

🗺️

Uni Map

Interactive SVG campus map with all buildings clickable. Pan, zoom, and click any building to jump to its full directory entry.

📋

Directory

Searchable, filterable directory of every building with services, facilities, clubs, opening hours, rules, and a Get Direction button.

🏗️

Floor Plans

SVG floor maps for every building show room layouts per floor. Destination rooms are highlighted when navigating.

🧭

Indoor Navigation

Type "from Cafeteria to Table Tennis Club in B11" and get step-by-step walking directions with a floor mini-map.

🕓

Chat History

All conversations saved locally with a GPT-style sidebar. Reload any past session, delete old ones, or start fresh anytime.

The process

How Image Recognition Works

1

Student uploads a photo

Any photo of an RSU building — entrance, lobby, lab, cafeteria, corridor — inside or outside.

→
2

Google Vision API analyzes it

The image is sent to Google Cloud Vision which returns labels, objects, and landmark detections.

→
3

Flask matches to campus DB

Labels are matched against each building's keyword list. The best match is returned with a confidence score.

→
4

Rich info card displayed

Building name, services, facilities, clubs, hours, floor map button, and Google Maps direction link.
